# 开发路线与阶段验收

> 历史路线快照，不作为当前执行清单。当前权威边界见
> [[16-比赛边缘自治架构与新Session交接]]、

## 总路线

```text
M0：接口摸底和样本采集
M1：SLAM Gateway P0 输出
M2：安全闭环和局部障碍摘要
M3：拓扑点与 PCD 重定位状态机
M4：本地 LLM 只读规划
M5：RGB-D 语义增强
M6：毫米波雷达与外接 NX 增强
```

## M0 接口摸底

目标：

1. 抓 `rt/slam_info` 原始 JSON。
2. 抓 `rt/slam_key_info` 原始 JSON。
3. 测 `/utlidar/cloud` 频率和带宽。
4. 测 `/uslam/localization/odom` 和 `/utlidar/robot_pose`。
5. 确认 `slam_operate 1102 / 1201 / 1202` 请求响应。

完成标准：

```text
有一批可离线回放的真实样本。
```

## M1 SLAM Gateway

目标：

```text
CurrentPose
LocalizationState
SlamHealth
NavigationTaskState
```

完成标准：

1. 能持续读位姿。
2. 能判断位姿是否过期。
3. 能判断 `localized / degraded / lost`。
4. 能知道目标是否到达。

## M2 安全闭环

目标：

```text
LocalObstacleSummary
SafetyDecision
pause_navigation
resume_navigation
```

完成标准：

1. 前方近距离障碍触发暂停。
2. 定位丢失触发停止任务。
3. 导航失败触发人工确认。
4. 安全层不依赖 LLM。

## M3 拓扑点与重定位

目标：

```text
MapState
RelocationState
TopologyNode
RelocationAnchor
```

完成标准：

1. 支持 `701_center`、`701_door_inside`。
2. 能区分 `map_loaded` 和 `localized`。
3. 跨地图切换必须经过锚点重定位。

## M4 本地 LLM 只读规划

目标：

1. 构造 `WorldState summary`。
2. 本地 LLM 输出 JSON 工具调用。
3. 只读运行，不直接执行。
4. 记录模型错误案例。

完成标准：

```text
LLM 可以稳定生成子目标，但所有执行仍由人工或规则确认。
```

## M5 RGB-D 语义增强

目标：

1. 接深度相机。
2. 完成外参标定。
3. 输出 `SemanticObject`。
4. 支持关键帧上传。

完成标准：

```text
能识别人 / 门 / 桌椅 / 箱子等近场目标，并带距离信息。
```

## M6 毫米波雷达与外接 NX

目标：

1. 外接 NX 处理雷达数据。
2. 输出 `RadarTrack`。
3. 主机器狗只接收 track / risk event。
4. 用于动态目标冗余感知。

完成标准：

```text
弱光或视觉受限时，仍能检测移动目标并触发安全策略。
```

## 当前最该做

## 2026-05-24 路线校正

当前项目已经跑到 M3/M4 之间：SLAM 状态读取、registry、中文目标解析、LLM dry-run、安全兜底和统一入口都已经具备雏形。接下来不应继续扩大传感器范围，而应先把真实点位闭环做扎实。

近期优先级：

```text
1. 校准 needs_calibration 点位。
2. 每次真实执行前输出安全摘要。
3. 真实导航只选短距离、有人看护、可遥控中止的目标。
4. 到点后记录 final_distance_m 和现场肉眼偏差。
5. 把 calibrated pose 写回 registry 并提交。
6. 拍照和语音作为到点后工具，不进入实时控制链路。
7. 保持 hybrid 路径为默认，真实 LLM 只用于复杂语义验证。
```

## 当前阶段验收口径

### 点位验收

```text
至少 3 个点从 needs_calibration 变为现场校准点。
每个点至少完成 2 次 dry-run 和 1 次真实低速导航验证。
```

优先点：

1. `yin_siyuan_station`：当前机器狗已在附近，可作为近距 hold 与校准参考点。
2. `zhao_bo_office_front`：办公室门口拍照点，是比赛展示价值最高的目标之一。
3. `yang_shuyang_station` 或 `room_701_corridor`：验证工位与走廊两类目标。

### 执行链路验收

```text
中文输入能解析到正确 node_id。
执行前摘要能显示目标、距离、速度、mode、是否拍照、是否 needs_calibration。
已在目标附近时强制 safe_hold。
未知目标强制 human_confirm。
低电量非紧急任务强制 human_confirm 或回充。
弱网时强制 semantic_only 并丢弃 raw_video/dense_pointcloud/high_rate_images。
```

### 日志验收

```text
每次现场执行都能找到：
用户输入
模型或 hybrid 输出
SLAM command
preflight 结果
执行结果
到点采样
最终偏差
人工备注
对应 git commit
```

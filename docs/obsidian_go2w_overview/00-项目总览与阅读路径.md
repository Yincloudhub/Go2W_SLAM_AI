# GO2W 边缘自治项目总览

这组笔记是当前机器狗项目的整体文档，用来把 SLAM、PCD 地图、拓扑点、LiDAR 几何感知、深度相机、毫米波雷达、本地 LLM、弱带宽交互和比赛展示统一到一个清晰架构里。

核心定位：

> 以 GO2W 官方 SLAM / Navigation 为底层执行底座，在外层构建 SLAM Gateway、语义地图管理、多传感器感知、实时安全闭环和本地 LLM 任务规划，实现面向弱带宽远程交互的边缘自治系统。

## 当前最重要的工程判断

1. 第一阶段不重写官方 `unitree_slam` 内核，而是在外层做 `SLAM Gateway`。
2. `PCD` 地图加载不等于定位成功，必须建立 `MapState` 与 `LocalizationState`。
3. LiDAR 先做几何障碍摘要和动态目标跟踪，不先上重型 3D 深度学习检测。
4. 深度相机适合补视觉语义，但不应一开始接入 SLAM 主闭环。
5. AWR2243 毫米波雷达和外接低配 NX 可以作为第二阶段创新增强。
6. 本地 LLM 不进入实时控制环，只消费低频 `WorldState summary` 并输出工具调用。
7. 安全层必须独立于 LLM，能自主暂停、急停、限速和请求重规划。
8. 语义不是 SLAM 自动产生的，而是由 `PCD pose + registry name/alias/tag + WorldState summary` 逐层绑定出来的。

## 项目主线

```text
官方 SLAM / Navigation
        ↓
SLAM Gateway
        ↓
MapManager + LocalizationManager
        ↓
LiDAR / RGB-D / mmWave 感知摘要
        ↓
WorldStateBuilder
        ↓
SafetySupervisor
        ↓
Event / Summary Gate
        ↓
Local LLM Planner
        ↓
Task Executor
```

## 当前近期目标

当前最小闭环已经进入真机 dry-run 和低速现场验证阶段。近期目标从“接口摸底”调整为：

```text
校准真实拓扑点
稳定中文目标解析
执行前输出安全摘要
用 hybrid 路径处理常用目标
真实 LLM 只处理复杂语义
到点后自动 pause 并记录 final_distance
每次现场实验写入 JSON/CSV 和 Obsidian 日志
```

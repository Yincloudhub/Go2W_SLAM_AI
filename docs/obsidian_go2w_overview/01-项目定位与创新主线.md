# 项目定位与创新主线

## 项目名称建议

面向弱带宽远程交互的四足机器人语义感知与边缘自治系统。

## 要解决的问题

传统远程操控机器狗在弱网、遮挡、复杂室内环境下容易出现：

1. 连续视频回传压力大。
2. 远端操作延迟高。
3. 操作员需要持续盯画面。
4. 机器人本地缺少任务级自主判断。
5. SLAM、感知和 LLM 容易各做各的，无法闭环。

本项目的目标不是让 LLM 直接控制机器狗，而是让机器狗本地具备结构化世界状态、任务级规划、安全监督和弱网摘要能力。

## 核心创新主线

### 1. SLAM 外层语义化封装

不直接改官方 SLAM 内核，而是建立：

```text
unitree_slam
=> SLAM Gateway
=> CurrentPose / LocalizationState / NavigationTaskState / SlamHealth
```

创新点在于把黑盒 SLAM 输出变成可复用、可验证、可被 LLM 消费的结构化接口。

### 2. 多空间 PCD 与拓扑锚点

PCD 地图只负责几何环境，拓扑点负责语义任务。

关键思想：

```text
地图加载 != 定位成功
拓扑点 != 重定位锚点
跨地图切换必须经过锚点验证
```

这让“701 到走廊巡视”变成可解释的任务链，而不是让 LLM 直接猜坐标。

### 3. 多传感器语义摘要

LiDAR、RGB-D、毫米波雷达不直接把原始数据塞给 LLM，而是统一输出：

```text
LocalObstacleSummary
SemanticObject
LidarObjectTrack
RadarTrack
RiskEvent
```

最终由 `WorldStateBuilder` 压缩成低带宽摘要。

### 4. 本地小模型闭环规划

大模型可以离线当教师生成样本，本地 Qwen3-4B 这类小模型负责运行时任务规划。

表达方式：

```text
云端大模型离线蒸馏
本地小模型在线闭环
安全层独立兜底
```

### 5. 弱带宽交互

弱网下不主传连续视频，而主传：

1. 当前任务阶段。
2. 定位状态。
3. 风险事件。
4. 关键帧。
5. 语义摘要。
6. 人工确认请求。

## 不建议宣传成什么

不要宣传成：

```text
LLM 直接控制机器狗
激光雷达识别万物
任意 PCD 位置自动定位
完全替代 SLAM 的大模型导航
```

更准确的表达是：

```text
以 SLAM 为几何基础，以多传感器摘要为环境理解，以本地LLM做任务级规划，以安全监督保证闭环可靠。
```

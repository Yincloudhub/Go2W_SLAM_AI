4. 安全链路

安全逻辑分三层：registry/topology 静态门、gateway/SLAM 权威门、本地局部感知辅助门。关键调整是： 不再要求“周围全部安全读数齐全”才允许重定位或执行；只要 SLAM/gateway 的权威安全状态允许，并且当前定位/位姿有效即可继续。 局部障碍只在新鲜、可信、明确危险时阻断。

安全点 当前规则 实现位置
Registry gate 真实执行时 map 不能是 demo/simulation；当前默认 go2w_real_site。 scripts/run_robot_closed_loop.py、cpp/src/operator_panel.cpp
Topology target gate 目标点带 disabled、deleted、needs_calibration 等阻断标签时不能真实导航。 scripts/run_robot_closed_loop.py、C++ task queue safety
Gateway/SLAM gate world_state.safety.allow_navigation 是硬门，SLAM/gateway 是真实执行权威。 src/edge_autonomy/gateway_safety.py、cpp/src/safety_gate.cpp、robot/.../safety_supervisor.cpp
Localization gate 接受 localized、localized_or_tracking、tracking、degraded，但位姿不能过期或无效。 world_state_v1.py、gateway_safety.py、C++ WorldState v1
Local obstacle advisory 局部感知不是“必须全方向安全”的前置条件；只有新鲜可信且明确危险时阻断。 gateway_safety.py、safety_gate.cpp

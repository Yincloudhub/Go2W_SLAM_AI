## 2026-06-12 比赛安全链精简决策

用户确认移动 baseline 测试稍后进行，本轮不要求移动机器狗。

当前结论：此前安全机制存在重复裁决，Web、Python 和 C++ 兼容层都在重新解释
Gateway 已经给出的定位、点云、净空和置信度结论。比赛主路径收敛为：

```text
LLM / SemanticRouter
  -> TaskQueue
  -> Operator execution_enabled
  -> Python supervised executor
  -> SlamGateway target authorizer
  -> SlamGateway SafetySupervisor
  -> Unitree chassis
```

职责边界：

- LLM 只做意图、目标和任务拆解，不决定安全阈值。
- UI 的 `execution_enabled` 只表示人工允许尝试执行。
- D435 在 Web 层只显示前视深度诊断，不阻断 UI 解锁；Gateway 可在 XT16
  有效时保守融合前向深度，但 D435 不能单独授权导航。
- Python `gateway_safety.py` 只读取 Gateway 的 `allow_navigation/reason`。
- SlamGateway 是唯一运动安全权威，运行中 watchdog 负责暂停。
- XT16 五场标定、地图/PCD 哈希和 Git 绑定保留为赛前验收工具，不进入比赛主 UI。

本轮代码变化：

- 撤回尚未提交的 XT16 五场标定 Web/API 大面板。

Keep versioned code separate from robot runtime state.

The robot can push and pull code through its own SSH key, while large or machine-local files stay outside git.

## Versioned Robot Files

Robot deployment helper files are tracked under:

```text
robot/
```

Install them on the robot with:

```bash
cd /home/unitree/Go2W_SLAM_AI
bash robot/llm_runtime/install_runtime_files.sh
```

This copies:

```text
robot/llm_runtime/ask_qwen.sh
```

to:

```text
/home/unitree/llm_runtime/scripts/ask_qwen.sh
```

## Explicitly Not Versioned

Do not commit:

- `*.gguf`
- llama.cpp `build/`
- `/home/unitree/models`
- `/home/unitree/llm_runtime/llama.cpp/build`
- runtime logs
- generated eval artifacts
- point clouds, bags, maps generated by the robot

The top-level `.gitignore` already excludes model files, build outputs, artifacts, and common robot runtime files.
